1.本游戏以中国游戏界第一次网络大战我的世界VS迷你世界。本游戏参照了史实。目前本游戏已更新到4.2版本。\
 \
2.首先你进入页面 看到一个设置页面。根据你的电脑信息进行设置。按F键可以进入全屏。\
 \
 3.然后进入到阵营选择，你可以选择我的世界方，迷你世界方，以及观察者模式。\\
3a.当你在选择阵营的时候，会进入到一个难度选择，分为简单、普通、困难，默认普通。此项也决定了观察者模式的AI\
3b.当你来到我的世界方的时候，可以点击鼠标左键进攻灰色区域，右键已占领的位置 也就是蓝色，可以进行防御对方一次攻击。\
特殊技能，当我的世界方领土低于全图的15%，触发条件：首先 触发萨拉热窝事件，官司胜利，将会获取对方的以占领领土的百分之 15%。\
​3c.迷你世界方，同理，左键占领灰色区，右键防御。\
​特殊技能，萨拉热窝事件，开启之后可以对对方进行攻击。\
 \
 
​4.触发萨拉热窝事件的条件，任意一方领土大于全图的的25%。即可对对方攻击。\
​ \
​5.然后我本游戏还有士气条，占领灰色领土减少5 士气，占领敌方领土 损耗 10 士气。
